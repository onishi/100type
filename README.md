# 百人一首タイピング

上の句が出たら、下の句をローマ字で打つ——小倉百人一首 100 首のタイピング練習ゲームです。
ビルド不要の静的サイト（HTML + CSS + ES Modules）で、GitHub Pages にそのまま乗ります。

## 遊び方

1. 出題数（5 / 10 / 25 / 100 首）、出題順（ランダム / 番号順）、難易度を選ぶ
2. `Enter` かボタンでスタート
3. 表示された上の句に続く**下の句**をローマ字で入力する
4. 全首打ち終わると、時間・打鍵/分・正確率・ミス数と段位が出ます

日本語入力（IME）は**オフ＝直接入力**にしてください。オンのまま打つと画面に警告が出ます。

### 難易度

| | 表示されるもの |
| --- | --- |
| 初級 | 下の句のかな＋ローマ字 |
| 中級 | 下の句のかなのみ |
| 上級 | 下の句の漢字仮名交じり文のみ（読みは自分で） |

## ローマ字入力

主要な入力ゆれに対応しています。打ち方は 1 通りではありません。

- `し` → `shi` / `si` / `ci`、`つ` → `tsu` / `tu`、`ふ` → `fu` / `hu`、`じ` → `ji` / `zi`
- `ん` → `nn` / `n`（母音・な行・や行の前では `nn` が必要）
- `っ` → 次の子音の重ね（`matte`）でも `ltu` / `xtu` でも可
- 拗音（`きゃ`=`kya`、`しゃ`=`sha`/`sya` など）、歴史的仮名遣いの `ゐ`=`wi`、`ゑ`=`we`、`づ`=`du`

歌のテキストは歴史的仮名遣いの読み（かるたの読み札に準じた表記）を採用しています。

## 開発

```bash
npm test     # ローマ字入力エンジンのテスト（全 100 首が打ち切れることも検証）
npm start    # http://127.0.0.1:8123 でローカル起動
```

### 構成

```
index.html          画面（スタート / プレイ / 結果）
src/styles.css      スタイル（ライト・ダーク両対応）
src/main.js         ゲーム進行・入力処理・記録
src/romaji.js       かな→ローマ字の入力判定エンジン
src/data/poems.js   小倉百人一首 100 首（上の句・下の句・読み・作者）
test/               ローマ字エンジンのテスト
```

ローマ字判定は、かなを「チャンク」に分解し、各チャンクの入力候補を並列に追跡する NFA として実装しています。
`shi` と `si` のように途中まで同じ入力が分岐しても、打ち終わるまで両方の可能性を保持します。

## デプロイ

`.github/workflows/deploy.yml` が push のたびに GitHub Pages へ公開します（ビルド工程なし）。

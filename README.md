# 百人一首タイピング

上の句が出たら、下の句をローマ字で打つ——小倉百人一首 100 首のタイピング練習ゲームです。
ビルド不要の静的サイト（HTML + CSS + ES Modules）で、GitHub Pages にそのまま乗ります。

## 遊び方

1. 出題数（5 / 10 / 25 / 100 首）、出題順（ランダム / 番号順）、詠み待ち、難易度を選ぶ
2. `Enter` かボタンでスタート
3. まず**上の句だけ**が表示され、音声合成が上の句を詠み上げます。少し置いてから下の句が出るので、続けてローマ字で入力する
4. 全首打ち終わると、時間・打鍵/分・正確率・ミス数と段位が出ます

下の句が出るまでの「詠み待ち」は なし / 2秒 / 4秒 / 8秒 から選べます。
待っているあいだも入力は受け付けるので、覚えていれば表示を待たずに打てます
（打ったぶんのかなだけが表示されます）。`Space` を押せば待たずに表示できます。
経過時間は最初の打鍵から計測するので、待っている時間は記録に影響しません。
読み上げが待ち時間より長いときは、詠み終わるまで下の句を伏せたままにします。

## 音

- **詠み上げ** — Web Speech API（音声合成）で上の句を読み上げます。五・七・五を一句ずつ
  別の発話として読み、あいだに約 0.4 秒の間を置きます。読んでいる句は画面上でも色が変わります。
  歴史的仮名遣いのままでは読みが崩れるため、100 首すべてに読み上げ用の現代仮名遣い
  （`kamiSpeech`）を持たせています。日本語の音声が入っていないブラウザでは自動的に無音になり、
  その旨を表示します。
- **効果音** — Web Audio API で合成しています（音声ファイルなし）。打鍵音、ミス音、
  一首打ち終えたときの鈴の音、全首終了のアルペジオ。
- 設定画面の「音」でそれぞれ切り替えられるほか、プレイ中は「音を止める」でまとめて消せます。

日本語入力（IME）は**オフ＝直接入力**にしてください。オンのまま打つと画面に警告が出ます。

### 難易度

| | 表示されるもの |
| --- | --- |
| 初級 | 下の句のかな＋ローマ字 |
| 中級 | 下の句のかなのみ |
| 上級 | 下の句の漢字仮名交じり文のみ（読みは自分で） |

いずれの難易度でも、詠み待ちのあいだ下の句は伏せられます。

## ローマ字入力

主要な入力ゆれに対応しています。打ち方は 1 通りではありません。

- `し` → `shi` / `si` / `ci`、`つ` → `tsu` / `tu`、`ふ` → `fu` / `hu`、`じ` → `ji` / `zi`
- `ん` → `nn` / `n`（母音・な行・や行の前では `nn` が必要）
- `っ` → 次の子音の重ね（`matte`）でも `ltu` / `xtu` でも可
- 拗音（`きゃ`=`kya`、`しゃ`=`sha`/`sya` など）、歴史的仮名遣いの `ゐ`=`wi`、`ゑ`=`we`、`づ`=`du`

歌のテキストは歴史的仮名遣いの読み（かるたの読み札に準じた表記）を採用しています。

## 開発

```bash
npm test     # ローマ字入力エンジンのテスト（全 100 首が打ち切れることも検証）
npm start    # http://127.0.0.1:8123 でローカル起動
```

### 構成

```
index.html          画面（スタート / プレイ / 結果）
src/styles.css      スタイル（ライト・ダーク両対応）
src/main.js         ゲーム進行・入力処理・記録
src/romaji.js       かな→ローマ字の入力判定エンジン
src/audio.js        読み上げ（音声合成）と効果音の合成
src/data/poems.js   小倉百人一首 100 首（上の句・下の句・読み・読み上げ用の現代仮名遣い・作者）
test/               ローマ字エンジンのテスト
wrangler.jsonc      Cloudflare Workers の設定（dist/ を静的配信）
```

ローマ字判定は、かなを「チャンク」に分解し、各チャンクの入力候補を並列に追跡する NFA として実装しています。
`shi` と `si` のように途中まで同じ入力が分岐しても、打ち終わるまで両方の可能性を保持します。

## デプロイ

Cloudflare Workers（静的アセット）で公開しています。

- 公開 URL: <https://100type.wagaya.workers.dev>
- 設定: `wrangler.jsonc`（`dist/` をそのまま配信するだけ。ビルド工程は index.html と src/ の複製のみ）

手元から手動で出す場合:

```bash
export CLOUDFLARE_API_TOKEN=...   # Workers Scripts:Edit 権限
export CLOUDFLARE_ACCOUNT_ID=...
npm run deploy
```

GitHub Actions（`.github/workflows/ci.yml`）は push のたびにテストを実行し、
リポジトリに `CLOUDFLARE_API_TOKEN` と `CLOUDFLARE_ACCOUNT_ID` の Secrets が
設定されていれば続けてデプロイします。未設定の場合はデプロイだけスキップします
（ワークフローは失敗しません）。
